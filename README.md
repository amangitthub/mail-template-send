# 📧 Mail Template Send

### Create • Preview • Copy • Send

A simple and modern web-based **HTML Email Template Editor** that helps you
create beautiful email templates, preview them instantly, and copy the
rendered design directly into Gmail.

🌐 **Live Demo:**  
https://amangitthub.github.io/mail-template-send/

---

## ✨ Features

- 🎨 Live HTML email preview
- ⚡ Instant design rendering
- 📋 Copy rendered email design
- 📧 Easily paste into Gmail
- 📱 Responsive email preview
- 🖥️ Desktop & mobile preview
- 🧩 Ready-to-use email templates
- 🚀 No backend required
- 🔒 Runs completely in the browser
